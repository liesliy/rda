审计范围与方法

从宇树科技（Unitree Robotics）在 HuggingFace 发布的公开数据集中，选取了两个具有代表性的 LeRobot v3.0 格式数据集，每个数据集抽取前 2 个 Episode 进行全量审计。视频文件（videos/）均已下载到本地并验证可解码。

行为特征观测

L1 全部通过后，L2/L3 层提供的是行为特征描述。这些是数据的客观画像，不是质量判决。

idle_ratio：有效运动比

WBT 28%~33%，Dex3 30%~48%。超过一半的帧处于低运动状态。遥操作数据中，操作者思考、定位、等待的时间都会被记录下来。这个指标对训练效率有参考意义——如果大量帧的运动信息接近零，跳帧采样可能是一个优化方向。

action_discontinuity：动作跳变

WBT 6~9 个 spike，Dex3 44~146 个 spike。两个数据集的操作模式差异明显。WBT 是全身遥操作拿枕头，动作相对连贯；Dex3 是三指灵巧手做面包，手指需要频繁微调抓握姿态和力度，动作天然更细碎。Dex3 Episode 1 的 146 个 spike 值得结合视频看看具体片段。

结论

审计结果

宇树这两套公开数据集在数据完整性层面没有问题——4 个 episode 全部通过 L1 检查。行为层面的 idle_ratio 和 action_discontinuity 反映了不同任务类型（全身遥操作 vs 灵巧手精细操作）的差异，这些是数据特征，不是数据缺陷。

审计过程中 RDA 自身暴露了视频路径解析的问题，已记录待修。工具本身也需要被审计。
